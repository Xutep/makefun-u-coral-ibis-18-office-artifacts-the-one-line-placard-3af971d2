A deterministic program that writes a one-line museum placard for an ordinary office object, treated as an ancient artifact from a lost civilisation. It holds a small curated set of candidate placards, scores each one on label craft (catalogue date, material, provenance or donor, dry structure, economy of length), and writes the best-scoring one to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
